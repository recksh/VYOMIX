Analysis Guide
MODULE A Dynamic Anomaly Detection

Checks whether a component behaves abnormally compared with its lot population using the burn-in measurements. A component is flagged when its anomaly score reaches the existing population threshold.

MODULE B 168h Drift Prediction

Uses early burn-in measurements to forecast future 168-hour behaviour and identify components with increasing drift or predicted risk.
